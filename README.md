# STRIXY — бизнес-модель сети

Промо-сайт / презентация авторской модели развития сети STRIXY.

## Концепция

Последовательное развитие без кредита:

**Сокол → Грязовец → Шексна**

Ключевая идея: следующая точка открывается только после подтверждения экономики предыдущего этапа.

## Рабочие параметры модели

- Стартовый капитал: **3,9–4,0 млн ₽**
- Зрелая выручка Сокола: **800 000 ₽ / мес**
- Зрелая выручка Грязовца: **500 000 ₽ / мес**
- Зрелая выручка Шексны: **500 000 ₽ / мес**
- Зрелый оборот сети: **1,8 млн ₽ / мес**
- Первичный запуск одной точки: **≈ 1 213 773 ₽**
- Остаток франшизного платежа: **340 000 ₽**
- Рассрочка: **34 000 ₽ × 10 месяцев**
- Полная стоимость с отложенной частью: **≈ 1 553 773 ₽**
- Аренда + коммунальные: **до 40 000 ₽ / мес**
- Базовый чек: **500 ₽**
- Материалы: **8%**
- Эквайринг: **2%**
- Рабочая модель ФОТ: **≈49,5%**
- Фонды: **15 000 ₽ амортизация + 15 000 ₽ команда / точка**
- Управляющий на первом этапе: **не заложен**

При базовых рабочих допущениях зрелая сеть даёт ориентир **≈457 500 ₽ операционного результата до налога / мес**. Это расчётная модель, а не гарантия финансового результата.
